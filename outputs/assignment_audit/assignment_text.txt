DEEP LEARNING PROJECT 
 
Sub-Course Learning Objective: 
1. SUB-CLO082-5 : Students are able to present the results of implementing design, 
analysis, and evaluation of deep learning implementation in a particular case study (P2) 
 
Type: Project (Group assignment) 
Your final project will require you to create a deep learning model using a neural network to 
address a case study, with the following requirements: 
1. The dataset used must be primary data (collected by scraping, manual image capture, 
etc.). The data can be text, images, signals, audio, etc. 
2. The dataset must have a minimum of 100 rows for images and 10,000 rows for other data 
types. 
3. The model must use a neural network algorithm; pre-training is permitted. 
4. The model must be evaluated using metrics relevant to the case study. 
5. Model deployment is a plus. 
There are two stages of project assessment: 
1. Week 7th: Presentation of scraping/dataset acquisition results (data sources, data 
acquisition process, EDA). 
2. Week 13th and 14th: Presentation of project final. 
Submission 1 – Week 7th: 
 The assignment must be submitted before week 7th, include: 
o PPT for the presentation slides. 
o PDF of the report (template provided). 
o Dataset in .xls or .csv, or .zip, or link of the dataset. 
 It is not permitted to use the same research title as another group. 
 File name format: IS794-Deep Learning-ClassXX-GroupXX-Week7.zip 
For example: IS794-Deep Learning-A-Group_Fantastic-Week7.zip
