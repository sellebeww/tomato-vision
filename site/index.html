Klasifikasi Tingkat Kesegaran Tomat Menggunakan Convolutional Neural Network (CNN) Berbasis TensorFlow

CNN dilatih dari nol dengan TensorFlow, lalu dijalankan langsung di browser. Tiga kelas kondisi visual. Evaluasi berbasis sesi pemotretan dan validasi silang.

HASIL ANALISIS

◎

Hasil akan tampil di sini

Model menampilkan prediksi dan probabilitas setiap kelas. Periksa kembali hasil yang ditandai “perlu tinjauan”.

Model ini dilatih dari foto yang sangat terbatas (60 foto berlabel dari 11 sesi pemotretan), sehingga bisa salah pada pencahayaan, latar, kamera, atau varietas yang berbeda. Gunakan sebagai alat bantu, bukan penentu.

Batas penggunaan: klasifikasi kondisi visual, bukan pemeriksaan keamanan pangan. Tidak mendeteksi banyak buah. Pemeriksaan warna hanya menandai gambar yang hampir tanpa warna tomat; objek merah lain tetap bisa diberi probabilitas tinggi. Foto diproses sepenuhnya di perangkat Anda dan tidak dikirim ke server mana pun.

Protokol evaluasi

    Ablation: satu variabel per eksperimen

    Validasi silang 5 fold berbasis sesi × 5 seed (25 run per baris). Akurasi adalah prediksi out-of-fold, rata-rata ± simpangan baku antar seed.

    Kurva pembelajaran model final

    Model final dilatih ulang pada seluruh data development tanpa data validasi, dengan jumlah epoch dan jadwal learning rate dari median run validasi silang.

    Latih di komputer sendiri

    Training dan pelabelan membutuhkan Python 3.11 dan TensorFlow, sehingga tidak berjalan di halaman statis ini.

    git clone https://github.com/sellebeww/tomato-vision.git
cd tomato-vision
python3.11 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.app                       # aplikasi lengkap di http://127.0.0.1:7860
python -m src.cv_study protocol         # studi own_v2 (lihat README)
python -m src.export_web                # perbarui demo statis
